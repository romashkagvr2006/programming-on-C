-------------------------
Команды - функции (буква)
-------------------------

Список команд подаваемых из командной строки

a..f,A..F - шестнадцатиричные цифры

G - СТАРТ
O - СТОП
I - отключить фильтрацию ФВЧ
D - включить фильтрацию ФВЧ
P - начать дополнительную передачу данных на IP адрес = XXX.XXX.XXX.200
S - прекратить дополнительную передачу данных на IP адрес = XXX.XXX.XXX.200
M - программная перезагрузка регистратора
Q - прервать калибровку
Y - системная информация (MAC, IP, Version ..)

Технологические команды (только для разработчика)

Ra,l - читать l чисел ram[a] --> ответ в файле log.txt (чтение Port)
N,а,1;n,a,1 - открыть директорию FLASH (a равняется от 0 до 10), открыть корневую директорию (a равняется 20)
